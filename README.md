# FACES dataset pre-study

Code for the negation and transcription experiments on the VR survey interviews of the
[FACES](https://texttechnologylab.github.io/FACES) project, recorded with
[InterView](https://texttechnologylab.github.io/InterView), built on
[Va.Si.Li-Lab](https://texttechnologylab.github.io/Va.Si.Li-Lab).

- `psrc/`: negation sampling, annotation aggregation and D-Neg training/evaluation
- `asr_bench/`: ASR benchmark against the post-edited reference transcripts
- `tests/`: unit tests

The interview data is not part of this repository.
